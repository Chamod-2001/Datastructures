# 📚 Data Structures in Java

A Java-based console application developed by **Chamod Lakshitha** to implement common data structures such as Stacks, Queues, Linked Lists, and Graphs.  
This project demonstrates the fundamental operations for each data structure and provides examples for testing.

---

## ✨ Features

- 🔹 **Stacks**: Implements stack operations like `push()`, `pop()`, `peek()`, `isEmpty()`, and `size()`.
- 🔹 **Queues**: Implements queue operations like `enqueue()`, `dequeue()`, `top()`, `isEmpty()`, and `size()`.
- 🔹 **Linked Lists**: Implements operations like `add()`, `remove()`, `contains()`, and `printList()`.
- 🔹 **Graphs**: Implements basic graph operations like adding nodes/vertices, adding edges, and BFS/DFS traversals.
- 🔹 All data structures include a demonstration of their functionalities via the `main()` method.

## 🚀 How to Run

1. Clone the repository:
    ```bash
    git clone https://github.com/YOUR_USERNAME/Datastructures.git
    ```

2. Navigate to the project directory:
    ```bash
    cd Datastructures
    ```

3. Open the project in IntelliJ IDEA or any Java IDE.

4. Run the `main()` method for each data structure to see the functionality in action. Each class (e.g., `MyQueue`, `MyStack`) contains a `main()` method to demonstrate its operations.

---


**Note:** Replace `YOUR_USERNAME` with your actual GitHub username for the clone URL.
